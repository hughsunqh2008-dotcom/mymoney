## 五、我遇到的问题和解决过程
@classmethod
缺少该修饰后不能生成对应cls并返回
@classmethod @staticmethod
### 正则跨过了括号，把有意义的内容吃掉了
- 现象：`(退款)星巴克(国贸店)` 整个变成空字符串
- 我一开始以为：把 `+` 改成非贪婪 `+?` 就够了
- 实际根因：`+?` 只控制"吃多少"，不禁止"跨过某些字符"。
            `.` 本身能匹配括号，所以它会一直吃到能配上为止
- 怎么解决的：把 `.+?` 换成 `[^（）()]+?`
             ——用"排除字符类"明确禁止匹配括号
- 学到的：非贪婪 ≠ 不跨字符。要禁止跨字符必须用 `[^...]`

### 变量在 if 里赋值，if 之外用会崩
- 现象：解析没有"币种"列的文件时 NameError
- 实际根因：`if currency_col: tx_currency = ...` 条件不成立时
            变量从未被创建
- 怎么解决的：`tx_currency = row[currency_col] if currency_col else None`
- 学到的：只要变量在 if 里赋值，用之前必须想清楚"没进 if 时它是什么"

### 判断解析失败时逻辑写反了
- 现象：成功的行被丢弃，失败的行被当成功
- 实际根因：写成 `if not parsed_row: 收下`，
            `not None` 是 True，所以失败的行进了成功列表
- 怎么解决的：改成 `if parsed_row is None: 计入失败`
- 学到的：判断 None 要用 `is None`，不要用 `not`——
            因为 0、""、[] 也都是假值

## 八、卡住时怎么办

1. **读报错信息**，从第一行读起（不要只看最后一行）
2. 看不懂就把报错**关键词**粘进搜索框
3. 在出错那行前面加 `print()`，看**变量的实际值**
4. 值不对 → **往回找"这个值是从哪来的"**（错误几乎总在更早的地方）
5. 用**断点**：在 VS Code 里点行号左边设红点，按 F5 启动，然后单步走
6. 还不行 → 写一个**10 行以内的最小复现脚本**
7. **这时候才去查书**

**每个模块文件顶部的注释里都写了"卡住去哪查"**，精确到 Automate 的章节号。
